1. **Почему в Git ветвление дешёвое, а в SVN дорогое?**  
В Git ветка — это лёгкий указатель на коммит, создаваемый локально почти мгновенно. В SVN ветка — отдельный путь в центральном репозитории, для работы с которым нужны сервер, checkout или `switch`, а также последующие операции слияния.

2. **Можно ли сделать коммит в SVN без интернета?**  
Нет. SVN хранит историю на центральном сервере, поэтому для создания ревизии нужен доступ к нему. Без интернета можно только изменить файлы или подготовить patch. В Git локальные коммиты возможны офлайн.

3. **Когда SVN может быть предпочтительнее Git?**  
При работе с большими бинарными файлами, когда нужны блокировки, централизованный контроль доступа, частичный checkout, единая нумерация ревизий или простой линейный рабочий процесс.
